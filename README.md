MOD 12 LAB
COSTCO Simulator

Added Classes
Customer: Simulates customers shopping and joining the checkout queue.

Cashier: Simulates cashiers serving customers from the queue.

CheckoutQueue: Holds customer IDs waiting to check out using an ArrayBlockingQueue.

CostcoSimulation: Starts the simulation and asks the user for the number of customers, cashiers, and queue capacity.

You can test the simulation with different numbers of customers, cashiers, and queue sizes
